VOID: Video Object and Interaction Deletion

Sam Motamed, Collaborators
ECCV 2026

📄 Paper 💻 Code 📑 Supplement 🎥 Video

Abstract

VOID is a video inpainting framework designed to remove objects and their physical interactions from videos. Unlike prior approaches that focus only on visual completion, VOID explicitly models causal consequences such as falling objects, shadows, and collisions.

Method Overview

Given an input video and a user-specified object, VOID generates a counterfactual video in which the object and its interactions are removed while preserving physical plausibility.

Results

VOID produces physically consistent results even in complex interaction scenarios.
